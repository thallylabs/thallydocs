## Product updates and releases

<Update label="CLI 0.8.68" date="2026-09-30">
  The migration CLI now has dedicated Mintlify, Fern, and Docusaurus repository adapters. This release improves navigation, link, asset, API reference, translated-page, and local component handling across those sources. It also carries supported Docusaurus footer configuration into the generated site.

  The importer writes `migration-report.json` with warnings and validation results. Review that report and compare the local site with its source before publishing. See the [migration guide](/guides/migrating) and [CLI reference](/guides/cli-reference#migrate-existing-documentation).
</Update>
