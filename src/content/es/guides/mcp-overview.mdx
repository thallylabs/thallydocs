Thally proporciona dos servidores del Protocolo de Contexto de Modelo. El **servidor local** ayuda a un agente de codificación de IA a trabajar en un repositorio. El **servidor remoto** ayuda a un agente a investigar la documentación ya publicada por un sitio.

## MCP local y remoto

| | Servidor de autoría local | Servidor de sitio implementado |
| --- | --- | --- |
| Punto de conexión | `npx -y @thallylabs/mcp` o `npx --yes @thallylabs/cli@latest mcp` | `https://docs.example.com/api/mcp` |
| Transporte | stdio | HTTP transmisible |
| Acceso | Tu máquina y permisos del sistema de archivos | Público por defecto; de solo lectura y con límite de velocidad |
| Herramientas | 15 herramientas de proyecto y sitio | 4 herramientas de sitio |
| Úsalo para | Crear, editar, migrar, traducir y validar documentos | Buscar, leer, listar páginas y verificar disponibilidad |

## Lo que expone el servidor local

El paquete local registra 15 herramientas desde un registro compartido:

- **Crear y organizar:** `create_project`, `add_page`, `update_page`,
  `add_tab`, `list_pages`
- **Leer y buscar:** `read_page`, `search_docs`, `get_context`
- **Migrar y traducir:** `migrate_docs`, `import_docs`, `translate_docs`
- **Validar e inspeccionar:** `lint_project`, `semantic_search`,
  `agent_readiness`
- **Automatizar cambios de producto:** `sync_from_repo`

La mayoría de las herramientas actúan en un `projectDir` local. `semantic_search` y
`agent_readiness` consultan un `siteUrl` implementado. El servidor devuelve errores estructurados cuando faltan rutas o valores requeridos, para que tu agente pueda corregir la llamada en lugar de inferir un resultado.

## Conecta un sitio implementado

Reemplaza la URL de ejemplo con el origen del sitio de documentación.

<Tabs>

<Tab title="Codex">

```bash
codex mcp add product-docs --url https://docs.example.com/api/mcp
```

</Tab>

<Tab title="Claude Code">

```bash
claude mcp add --transport http product-docs https://docs.example.com/api/mcp
```

</Tab>

<Tab title="Cursor">

```json
{
  "mcpServers": {
    "product-docs": {
      "type": "http",
      "url": "https://docs.example.com/api/mcp"
    }
  }
}
```

</Tab>

</Tabs>

El punto de conexión implementado expone `search_docs`, `read_page`, `list_pages` y
`agent_readiness`. No puede editar el sitio. Los propietarios del sitio pueden deshabilitarlo desde el panel de administración, y las llamadas a herramientas públicas por defecto tienen un límite de 60 por minuto por IP.

## Comportamiento de escritura segura

El punto de conexión remoto público siempre es de solo lectura. Las herramientas MCP locales heredan los permisos del proceso que las inició, así que revisa cualquier solicitud que escriba archivos. `migrate_docs` requiere un destino nuevo o vacío; `import_docs` modifica un proyecto existente y solo debe usarse cuando una fusión en el lugar es intencional.

Continúa hacia la [referencia de herramientas MCP local](/guides/mcp-server) o la [guía MCP remota](/guides/remote-mcp) para cada herramienta y opción.
