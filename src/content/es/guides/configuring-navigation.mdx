Usa la navegación para reflejar los objetivos de tus lectores y el orden en que los completan. Empieza con un conjunto pequeño de grupos basados en tareas; añade una pestaña solo cuando una sección tenga una audiencia o un propósito distintos.

## El archivo docs.json

Toda la navegación está controlada por un único archivo en la raíz del proyecto: `docs.json`. Define las pestañas en la barra superior, los grupos de la barra lateral dentro de cada pestaña y el orden de las páginas.

## Estructura

```json
{
  "tabs": [
    {
      "tab": "Tab Label",
      "groups": [
        {
          "group": "Section Title",
          "pages": ["page-one", "page-two"]
        }
      ]
    }
  ]
}
```

## Pestañas

Cada entrada del array `tabs` crea una pestaña de navegación de nivel superior. Hay tres tipos.

### Pestaña de contenido

Una pestaña con grupos de barra lateral y páginas.

```json
{
  "tab": "Overview",
  "groups": [
    { "group": "Getting Started", "pages": ["introduction", "quickstart"] },
    { "group": "Core Concepts", "pages": ["authentication"] }
  ]
}
```

### Pestaña de referencia de API

Una pestaña que genera páginas automáticamente a partir de una especificación OpenAPI.

```json
{
  "tab": "API Reference",
  "api": {
    "source": "openapi.yaml",
    "tagsOrder": ["Pets", "Store"],
    "defaultGroup": "General"
  }
}
```

Varias pestañas pueden vincular su propia especificación. La primera pestaña de API enruta en `/api/default/...`; las pestañas de API adicionales enrutan en `/api/<tabId>/...`. Consulta [Varias especificaciones de API](/es/guides/api-reference-setup#varias-especificaciones-de-api) para un ejemplo completo.

### Pestaña de enlace

Una pestaña que enlaza a una ruta interna o URL externa.

```json
{
  "tab": "Changelog",
  "href": "/changelog"
}
```

## Grupos

Los grupos crean secciones etiquetadas en la barra lateral. Cada grupo tiene estos campos.

- **`group`** — el encabezado de sección que se muestra en la barra lateral
- **`pages`** — un array ordenado de IDs de página

Los IDs de página se corresponden con rutas de archivo bajo `src/content/`. Por ejemplo.

| ID de página | Ruta del archivo |
| --- | --- |
| `"introduction"` | `src/content/introduction.mdx` |
| `"guides/getting-started"` | `src/content/guides/getting-started.mdx` |
| `"api/reference"` | `src/content/api/reference.mdx` |

## Añadir una nueva sección

Para añadir una nueva sección en la barra lateral, añade un objeto de grupo a la pestaña correspondiente.

```json
{
  "tab": "Overview",
  "groups": [
    { "group": "Getting Started", "pages": ["introduction", "quickstart"] },
    { "group": "Advanced", "pages": ["webhooks", "pagination"] },
    { "group": "New Section", "pages": ["my-new-page"] }
  ]
}
```

## Reordenar

Las páginas aparecen en la barra lateral en el orden exacto indicado en el array `pages`. Los grupos aparecen en el orden en que están definidos en el array `groups`. Las pestañas aparecen de izquierda a derecha en el orden definido en el array `tabs`.

## Iconos de grupo

Añade un campo `icon` a cualquier grupo para mostrar un icono junto al encabezado del grupo en la barra lateral.

```json
{
  "group": "Getting Started",
  "icon": "book-open",
  "pages": ["introduction", "quickstart"]
}
```

Nombres de icono disponibles.

| Nombre | Icono |
| --- | --- |
| `book-open` | Libro / documentación |
| `code-simple` | Llaves de código |
| `grid-round` | Cuadrícula / resumen |
| `link-simple` | Enlace / URL |
| `wrench` | Herramientas / ajustes |
| `party-horn` | Funciones / celebración |
| `telegram` | Enviar / mensajería |
| `envelope` | Correo electrónico |
| `x-twitter` | X / Twitter |
| `message` | Chat / mensaje |

## Ocultar páginas, grupos y pestañas

Las páginas con `hidden: true` en su frontmatter se eliminan automáticamente de la barra lateral, los enlaces anterior y siguiente, y los sitemaps. Siguen siendo accesibles por URL directa. Si todas las páginas de un grupo están ocultas, el grupo se suprime de la barra lateral.

Define `hidden: true` en un grupo o una pestaña de `docs.json` para excluir una sección completa y mantener sus páginas accesibles por URL.

```json
{
  "group": "Internal",
  "hidden": true,
  "pages": ["internal/roadmap", "internal/notes"]
}
```

```json
{
  "tab": "Staff Only",
  "hidden": true,
  "groups": [...]
}
```

Consulta [Controla la búsqueda y la visibilidad de las páginas](/es/guides/seo-and-visibility) para ver más controles de indexación.

## Grupos anidados

Coloca un objeto de grupo dentro del array `pages` de otro grupo cuando una sección necesite un nivel adicional.

```json
{
  "group": "Deploy",
  "pages": [
    "guides/deploying",
    {
      "group": "Platforms",
      "pages": ["guides/deploy-vercel", "guides/deploy-cloudflare"]
    }
  ]
}
```

Evita estructuras más profundas. Si los lectores tienen que expandir varios niveles para encontrar una página, divide el material en pestañas más claras o reduce el número de categorías.

## Verificar la navegación

Ejecuta la vista previa local y sigue cada entrada nueva. Confirma que las migas de pan y los enlaces anterior y siguiente coincidan con la progresión prevista, y luego ejecuta estos comandos.

```bash
jq empty docs.json
npx --yes @thallylabs/cli@latest check
```
