`@thallylabs/mcp` es un servidor de [Model Context Protocol](https://modelcontextprotocol.io) que permite a herramientas de IA como Claude Code, Claude Desktop, Cursor y Windsurf crear, leer, actualizar y migrar proyectos de documentación Thally mediante lenguaje natural.

## Configuración

Añade `@thallylabs/mcp` a tu agente de programación o cliente de escritorio.

<Tabs>

<Tab title="Codex">

```bash
codex mcp add thally -- npx -y @thallylabs/mcp
```

</Tab>

<Tab title="Claude Code">

```bash
claude mcp add thally -- npx -y @thallylabs/mcp
```

</Tab>

<Tab title="Claude Desktop">

Añade esto a `claude_desktop_config.json`.

```json
{
  "mcpServers": {
    "thally": {
      "command": "npx",
      "args": ["-y", "@thallylabs/mcp"]
    }
  }
}
```

</Tab>

<Tab title="Cursor / Windsurf">

Añade esto a tu configuración de MCP.

```json
{
  "mcpServers": {
    "thally": {
      "command": "npx",
      "args": ["-y", "@thallylabs/mcp"]
    }
  }
}
```

</Tab>

</Tabs>

Una vez conectado, puedes hablar con tu documentación como si fuera un colaborador. Por ejemplo, *"Add a page about webhooks to the Guides tab"* o *"Migrate the Stripe docs into a new project"*.

## Herramientas

### Gestión de proyectos

#### `create_project`

Crea un proyecto a partir de la versión inicial inmutable actual. La versión fija una revisión exacta del runtime público y la comparten la CLI, MCP, la migración y los flujos de creación de Thally Cloud.

```
Create a new Thally project at ~/dev/my-docs with the name "Acme Docs"
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del nuevo proyecto |
| `projectName` | No | Se muestra en el encabezado y los metadatos |
| `description` | No | Se usa para SEO y OpenGraph |
| `brandPreset` | No | `primary` o `secondary` |
| `repoUrl` | No | URL de GitHub para los enlaces "Edit on GitHub" |
| `install` | No | Ejecuta `npm install` después de crear el scaffold (valor predeterminado: `true`) |

---

#### `add_page`

Crea una página MDX nueva y la registra en `docs.json`.

```
Add a page called "Authentication" to the Guides tab under a "Security" group
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `pageId` | Sí | Por ejemplo, `guides/private-docs`, sin la extensión `.mdx` |
| `title` | Sí | Título de la página (frontmatter) |
| `description` | No | Descripción de la página (frontmatter) |
| `content` | No | Cuerpo MDX (se usa un marcador de posición si se omite) |
| `tab` | No | Nombre de la pestaña (usa la primera de forma predeterminada) |
| `group` | No | Nombre del grupo (usa el primero de forma predeterminada) |
| `position` | No | `start` o `end` (valor predeterminado: `end`) |

---

#### `add_tab`

Añade una pestaña nueva de nivel superior a la navegación.

```
Add a "SDK Reference" tab to the project
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `tabName` | Sí | Etiqueta de la pestaña |
| `href` | No | Si se define, crea una pestaña de enlace de redirección (por ejemplo, `/changelog`) |
| `position` | No | `start` o `end` (valor predeterminado: `end`) |

---

#### `update_page`

Actualiza el frontmatter o el cuerpo de una página existente.

```
Update the "Getting Started" page to mention the new --yes flag
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `pageId` | Sí | Página que se va a actualizar |
| `title` | No | Título nuevo |
| `description` | No | Descripción nueva |
| `content` | No | Reemplaza el cuerpo existente |
| `mergeFrontmatter` | No | Campos adicionales del frontmatter que se van a fusionar |

---

#### `list_pages`

Enumera todas las páginas de un proyecto, organizadas por pestaña y grupo.

```
Show me all the pages in my docs project
```

### Migración

#### `migrate_docs`

Crea un proyecto Thally nuevo a partir de la plantilla canónica actual y luego importa en él un sitio de documentación público o un repositorio de documentación de GitHub. El directorio de destino debe ser nuevo o estar vacío; la herramienta nunca reutiliza el runtime de un sitio existente.

```
Migrate https://github.com/example/docs into a new Thally project at /tmp/example-docs
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `sourceUrl` | Sí | URL de documentación pública o URL de repositorio de GitHub |
| `projectDir` | Sí | Directorio de destino nuevo o vacío |
| `branch` | No | Rama de Git que se va a clonar (se detecta automáticamente de forma predeterminada) |
| `docsDir` | No | Subdirectorio de documentación del repositorio (se detecta automáticamente) |
| `platform` | No | `mintlify` o `docusaurus`; omítelo para detección automática, incluido Fern |
| `maxPages` | No | Número máximo de páginas de un sitio publicado que se van a importar (`1`–`1000`) |
| `apiKey` | No | Clave API de Anthropic para convertir archivos que no son Markdown |

#### `import_docs`

Importa documentación en un proyecto Thally existente sin reemplazar su runtime. Usa esta herramienta solo cuando quieras de forma intencionada fusionar contenido y navegación en el lugar.

```
Import https://github.com/example/api-docs into the existing Thally project at /workspace/docs
```

Las opciones de origen coinciden con `migrate_docs`; `projectDir` debe apuntar a un proyecto Thally existente.

### Lectura y búsqueda

Estas herramientas permiten a los agentes de IA consultar tu documentación como contexto, lo que resulta útil para crear funciones de IA sobre tu documentación.

#### `search_docs`

Busca en todas las páginas por palabra clave y devuelve resultados ordenados.

```
Search the docs for anything about rate limiting
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `query` | Sí | Consulta de búsqueda |
| `limit` | No | Número máximo de resultados que se van a devolver (valor predeterminado: `5`) |

---

#### `read_page`

Lee el contenido completo de una sola página por su ID.

```
Read the "guides/private-docs" page
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `pageId` | Sí | Por ejemplo, `guides/private-docs` |

---

#### `get_context`

Devuelve el contenido de documentación más relevante para un tema, dentro de un presupuesto de tokens. Es ideal para fundamentar respuestas de IA en tu documentación.

```
Get context about the authentication flow for up to 4000 tokens
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `topic` | Sí | Tema o pregunta |
| `maxTokens` | No | Presupuesto de tokens (valor predeterminado: `4000`) |

### Consultar un sitio desplegado

Estas herramientas consultan un sitio Thally **desplegado** por HTTP. Usan los mismos índices e informes que alimentan el sitio publicado, así que un agente puede razonar sobre documentación que no creó.

#### `semantic_search`

Ejecuta una búsqueda híbrida (texto completo y vectores) contra `/api/search` de un sitio desplegado, con el mismo índice de Orama que la paleta de comandos de la aplicación.

```
Semantic-search https://docs.example.com for "rotating API keys"
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `siteUrl` | Sí | URL base del sitio Thally desplegado |
| `query` | Sí | Consulta de búsqueda en lenguaje natural |
| `limit` | No | Número máximo de resultados (valor predeterminado: `8`) |
| `mode` | No | `hybrid` (predeterminado) o `fulltext` |

---

#### `agent_readiness`

Obtiene la puntuación de preparación para agentes (0–100) de un sitio desplegado, el mismo informe que `/api/agent-readiness` y `thally check`, con subpuntuaciones por señal y las páginas concretas que bajan la puntuación.

```
What's the agent readiness score for https://docs.example.com?
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `siteUrl` | Sí | URL base del sitio Thally desplegado |
| `minScore` | No | Umbral (0–100); marca aprobado o fallido en el resumen |

### Calidad

#### `lint_project`

Comprueba un proyecto en busca de errores y advertencias, como referencias de navegación rotas, archivos huérfanos y frontmatter faltante.

```
Check my docs project for any issues
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `fix` | No | Añade automáticamente las páginas huérfanas a la navegación (valor predeterminado: `false`) |

### Internacionalización

#### `translate_docs`

Traduce páginas de documentación a un idioma secundario con Claude AI. Requiere un bloque `i18n` en el `docs.json` del proyecto. Los archivos MDX traducidos se escriben en `src/content/{locale}/` para que los revises y hagas commit.

```
Translate my docs to Spanish
```

```
Translate only the introduction and quickstart pages to French
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Ruta del proyecto Thally |
| `locale` | Sí | Código del idioma de destino, por ejemplo `"es"` o `"fr"` |
| `pages` | No | Array de IDs de página que se van a traducir (omítelo para todas las páginas) |
| `force` | No | Sobrescribe los archivos de traducción existentes (valor predeterminado: `false`) |
| `apiKey` | No | Clave API de Anthropic (usa `ANTHROPIC_API_KEY` como alternativa) |
| `model` | No | Modelo de Claude que se va a usar (valor predeterminado: `claude-sonnet-4-6`) |

Consulta [Compatibilidad multilingüe](/es/guides/multi-language) para ver las instrucciones completas de configuración.

### Cambios de producto (flujo autogestionado)

#### `sync_from_repo`

Analiza un pull request fusionado con la configuración de seguimiento del `docs.json` del proyecto local. De forma predeterminada, previsualiza la tarea de documentación o la envía al repositorio de documentación para que el agente de documentación, sujeto a revisión, redacte un pull request.

Para Cloud Track, conecta fuentes de producto y superficies de conocimiento en Thally Cloud. El flujo gestionado usa ingesta durable de GitHub, impacto en el conocimiento de producto y acceso limitado al repositorio; no depende de esta herramienta MCP.

```
Preview the docs task for pull request 482 in acme/widget
```

| Parámetro | Obligatorio | Descripción |
|-----------|----------|-------------|
| `projectDir` | Sí | Proyecto Thally que contiene la configuración de seguimiento. |
| `repo` | A veces | Repositorio de producto como `owner/repo`; es opcional cuando se sigue exactamente un repositorio. |
| `pr` | No | Número del pull request fusionado; usa la última fusión de la rama seguida de forma predeterminada. |
| `dryRun` | No | Previsualiza sin enviar. Valor predeterminado: `true`. |
| `docsRepo` | Para enviar | Repositorio de documentación como `owner/repo`; es obligatorio cuando `dryRun` es `false`. |

El envío requiere `THALLY_GITHUB_TOKEN` o una GitHub App conectada con acceso al repositorio de documentación. La herramienta nunca fusiona el pull request de documentación generado.
