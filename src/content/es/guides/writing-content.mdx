## Crea una página

Añade un archivo bajo `src/content/`. Su ruta se convierte en la URL, así que `src/content/guides/invite-a-member.mdx` está disponible en `/guides/invite-a-member`.

## Conceptos básicos de MDX

Cada página de Thally es un archivo `.mdx`, Markdown con compatibilidad con JSX. Puedes usar la sintaxis estándar de Markdown y componentes de React en línea.

```mdx
# Heading

Regular paragraph with **bold**, *italic*, and `inline code`.

- Bullet lists
- Work as expected

1. Numbered lists too
```

## Frontmatter

Cada página necesita un bloque de frontmatter al principio.

```yaml
---
title: Page Title
description: A short summary for search results and meta tags.
---
```

| Campo | Obligatorio | Propósito |
| --- | --- | --- |
| `title` | Sí | Encabezado de la página y etiqueta de la barra lateral |
| `description` | Sí | Meta descripción y fragmento de búsqueda |

El título del frontmatter se renderiza automáticamente como encabezado de la página, así que no necesitas añadir un `# H1` en el cuerpo.

Consulta la [referencia de frontmatter](/es/guides/frontmatter-reference) para ver los campos de búsqueda, procedencia, visibilidad, operación de API y diseño de página.

## Bloques de código

Los bloques de código delimitados reciben resaltado de sintaxis automáticamente.

````mdx
```javascript
const greeting = 'Hello from Thally!'
console.log(greeting)
```
````

Usa `bash`, `typescript`, `python`, `json` o cualquier otro identificador de lenguaje compatible con Shiki.

## Avisos y notas

Usa el componente `<Note>` para destacar información importante.

```mdx
<Note type="info" title="Good to know">
  Notes support **Markdown** inside them.
</Note>

<Note type="warning" title="Heads up">
  This is a warning callout.
</Note>
```

Tipos disponibles. `info`, `warning`, `danger`, `tip`.

## Enlaces

Los enlaces estándar de Markdown funcionan tanto para páginas internas como externas.

```mdx
Check the [Quickstart](/quickstart) guide or visit [GitHub](https://github.com).
```

## Pestañas

Usa `<Tabs>` y `<Tab>` para mostrar contenido específico de plataforma o variantes sin bloques de código.

```mdx
<Tabs>

<Tab title="macOS">
Install with Homebrew:
\`\`\`bash
brew install your-cli
\`\`\`
</Tab>

<Tab title="Linux">
Install with apt:
\`\`\`bash
sudo apt install your-cli
\`\`\`
</Tab>

</Tabs>
```

Cada `<Tab>` admite contenido MDX completo dentro, como bloques de código, listas, avisos y más.

## Pasos

Usa `<Steps>` y `<Step>` para instrucciones secuenciales con círculos numerados y líneas conectoras.

```mdx
<Steps>

<Step title="Install">
Run the installer:
\`\`\`bash
npm install your-package
\`\`\`
</Step>

<Step title="Configure">
Create a config file and add your API key.
</Step>

</Steps>
```

## Tarjetas

Usa `<CardGroup>` y `<Card>` para crear cuadrículas de tarjetas enlazables para páginas de inicio o secciones de "próximos pasos".

```mdx
<CardGroup cols="2">

<Card title="Quickstart" href="/quickstart" icon="book-open">
Get up and running in five minutes.
</Card>

<Card title="API Reference" href="/api" icon="code-simple">
Explore the full API.
</Card>

</CardGroup>
```

Iconos disponibles. `book-open`, `code-simple`, `grid-round`, `link-simple`, `wrench`, `party-horn`, `telegram`, `envelope`, `x-twitter`, `message`.

## Imágenes y marcos

Coloca las imágenes en la carpeta `public/` y referéncialas con una barra inicial.

```mdx
![Screenshot](/images/image1.jpg)
```

Envuelve las imágenes en un `<Frame>` para obtener un borde con estilo y un pie de foto opcional. Los marcos se amplían al hacer clic de forma predeterminada.

```mdx
<Frame caption="System architecture overview">
  ![Screenshot](/images/image1.jpg)
</Frame>
```

Desactiva el zoom con `<Frame zoom={false}>`.

Para organizar assets, escribir texto alternativo, añadir descargas y revisar imágenes, consulta [Añade imágenes y archivos descargables](/es/guides/images-and-files).

## Enlaces ancla en encabezados

Cada encabezado de `h2` a `h6` es un enlace permanente. Al seleccionar el encabezado se copia la URL de la sección sin añadir un marcador visible al lado, así que puedes compartir una respuesta concreta y mantener la página visualmente limpia.

Los IDs de ancla se generan a partir del texto del encabezado. Los caracteres no latinos, como CJK, cirílico o letras latinas con acentos, se conservan en el ID, así que un encabezado como "Überblick" se convierte en `#überblick` y "日本語 API" en `#日本語-api`. Los encabezados duplicados en la misma página reciben un sufijo numérico (`-2`, `-3`, etcétera).

Cuando un encabezado contiene un enlace creado por ti, Thally renderiza el enlace permanente como un elemento separado solo para lectores de pantalla en lugar de anidar anclas, lo que mantiene el HTML válido y conserva el acceso por teclado y tecnología de asistencia a la URL de la sección.

Para definir un ancla personalizada, escribe el encabezado como un elemento JSX con una prop `id`.

```mdx
<h2 id="custom-anchor">My heading</h2>
```

El ID creado por ti se usa tal cual. Cuando no se proporciona un `id`, Thally genera uno a partir del texto del encabezado.

## Tablas

Las tablas estándar de Markdown se renderizan con el estilo adecuado.

```mdx
| Method | Endpoint | Description |
| --- | --- | --- |
| GET | /pets | List all pets |
| POST | /pets | Create a pet |
```

## Organización de archivos

Todo el contenido vive en `src/content/`. Puedes usar subdirectorios para organizar páginas relacionadas.

```
src/content/
  introduction.mdx          → /introduction (or / for the root)
  quickstart.mdx             → /quickstart
  guides/
    getting-started.mdx      → /guides/getting-started
    writing-content.mdx      → /guides/writing-content
```

La ruta de la URL coincide con la ruta del archivo relativa a `src/content/`, sin la extensión `.mdx`.

## Añade la página a la navegación

En `docs.json`, añade el ID de la página al array `pages` del grupo correspondiente. Para el ejemplo anterior, usa `"guides/invite-a-member"`. Consulta [Organiza tu navegación](/es/guides/configuring-navigation).

## Verifica la página

Abre la página en la [vista previa local](/es/guides/preview-locally), sigue sus instrucciones, prueba los enlaces y los componentes interactivos, y luego ejecuta estos comandos.

```bash
npx --yes @thallylabs/cli@latest check
npm run build
```
