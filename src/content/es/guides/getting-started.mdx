## Crea un proyecto local

Usa Node.js 22 (22.14 o posterior) o Node.js 24 o posterior. También se admite Node.js 20.19 o posterior. El proyecto predeterminado incluye las dependencias de compilación de la documentación. Las pruebas internas del framework y las herramientas de despliegue en Cloudflare quedan fuera de la instalación predeterminada.

Ejecuta la configuración interactiva.

```bash
npx create-thally-docs my-docs --install
```

La configuración solo pregunta por los valores que definen el proyecto inicial.

| Pregunta | Qué cambia |
| --- | --- |
| Nombre del proyecto | Encabezado, metadatos y contenido inicial |
| Descripción | Metadatos de búsqueda y redes sociales |
| Preset de marca | Tokens de color iniciales para modo claro y oscuro |
| Repositorio de GitHub | Enlaces de la barra de navegación y de soporte |
| Instalar dependencias | Si el sitio está listo para ejecutarse de inmediato |

Inicia el servidor local cuando termine el comando.

```bash
cd my-docs
npm run dev
```

Abre la URL que se imprime en la terminal. Empieza en [http://localhost:3040](http://localhost:3040).

## Usa los valores predeterminados de automatización

Usa `--yes` para aceptar los valores predeterminados y `--install` para instalar las dependencias en el mismo comando.

```bash
npx create-thally-docs my-docs --yes --install
```

Usa esta forma en un script, una evaluación temporal o un flujo de trabajo de agente. Puedes cambiar la identidad del producto más adelante en `src/data/site.ts` y `docs.json`.

## Migra documentación existente

Prefiere el repositorio fuente cuando tengas acceso a él. Una migración de repositorio puede conservar Markdown o MDX original, navegación, assets locales, snippets, locales, redirecciones y archivos OpenAPI que un sitio web público puede no exponer.

```bash
npx --yes @thallylabs/cli@latest migrate https://github.com/acme/docs acme-docs
```

También puedes migrar la URL de un sitio de documentación público.

```bash
npx --yes @thallylabs/cli@latest migrate https://docs.acme.com acme-docs
```

El flujo interactivo pregunta si la fuente usa Mintlify, Docusaurus, Fern o detección automática. Para ejecuciones sin interacción, selecciona el adaptador de forma explícita.

```bash
npx --yes @thallylabs/cli@latest migrate https://github.com/acme/docs acme-docs --platform mintlify --yes
```

<Note type="info" title="Revisa una migración antes de publicar">
Lee `migration-report.json` y resuelve los errores de validación. La validación de la migración ejecuta código importado en local, así que usa fuentes propias o de confianza. Ejecuta el proyecto migrado en local, revisa su navegación y sus assets, y luego ejecuta `npx --yes @thallylabs/cli@latest check`. El contenido importado sigue siendo tuyo para editarlo y reorganizarlo.
</Note>

## Qué crea el scaffold

| Ruta | Propósito |
| --- | --- |
| `src/content/` | Páginas MDX que tú controlas |
| `docs.json` | Configuración de navegación y funciones |
| `src/data/site.ts` | Identidad del producto, enlaces y valores de marca |
| `.github/workflows/` | Flujo de trabajo de validación para pull requests de documentación |

El runtime del framework ya está conectado. Puedes centrarte en el contenido y la configuración en lugar de editar las partes internas de Next.js.
