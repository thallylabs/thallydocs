## Primeros pasos con la documentación de API

Este sitio no incluye una especificación de API de ejemplo ni páginas de puntos finales generadas. Para publicar una referencia de API completa, deberás agregar tu propia especificación OpenAPI 3.x y conectarla a través de la configuración del proyecto.

## Cómo configurar tu referencia de API

Para publicar una referencia de API, agrega tu propia especificación OpenAPI 3.x y conéctala en `docs.json`. Sigue [Configurar una referencia de API](/guides/api-reference-setup) para las opciones de configuración admitidas y los pasos de validación. Esta guía cubre todo lo que necesitas saber sobre la configuración de puntos finales, la personalización de páginas de operaciones y la visibilidad de tu documentación de API para tus usuarios.
