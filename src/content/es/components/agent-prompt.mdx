Usa `<AgentPrompt>` cuando un lector pueda delegar la tarea documentada a un agente de codificación de IA. La página muestra una etiqueta de tarea breve y un botón **Copiar indicación**; las instrucciones completas permanecen ocultas hasta que el lector las copia.

## Ejemplo

<AgentPrompt
  title="Copiar una indicación para añadir una página"
  copyOnly
>

Añade o mejora una página enfocada en tareas en este proyecto de Thally sobre invitar a un miembro del equipo. Habrás terminado cuando la página sea precisa, sea detectable en la navegación, pase la validación de Thally y se represente correctamente en una compilación de producción.

Antes de editar, lee AGENTS.md si está presente, docs.json, package.json y las páginas existentes que hablen de equipos, roles, acceso o invitaciones. Prefiere actualizar la página que ya posee esta tarea. Crea un nuevo archivo MDX solo si los lectores necesitan una URL duradera distinta.

Escribe para un desarrollador o propietario del espacio de trabajo que complete la tarea por primera vez. Establece requisitos previos, explica los requisitos de permisos, proporciona pasos ordenados con etiquetas de interfaz de usuario exactas o comandos, muestra un ejemplo realista, cubre estados de fallo comunes y termina con una comprobación de éxito. No inventes comportamiento del producto: rastrea cada afirmación hasta el repositorio actual o identifícala para confirmación humana.

Mantén la etiqueta de la barra lateral corta con navTitle si es necesario. Reutiliza componentes incorporados de Thally solo cuando mejoren el escaneo. Ejecuta npx --yes @thallylabs/cli@latest check y npm run build, corrige los problemas causados por tus cambios y resume los archivos cambiados, los hechos verificados y las preguntas que quedan pendientes. No hagas commit, no hagas push, no despliegues ni modifiques archivos de marco no relacionados a menos que me lo pidas.

</AgentPrompt>

## Escribe una indicación confiable

Incluye el resultado, el alcance, los archivos o herramientas que el agente debe inspeccionar, los comandos de validación y las acciones que requieren aprobación separada. Usa marcadores de posición solo cuando el lector sepa que debe reemplazarlos.

| Prop | Tipo | Por defecto | Propósito |
| --- | --- | --- | --- |
| `children` | MDX | Obligatorio | Instrucciones de indicación y carga útil del portapapeles. |
| `copyOnly` | boolean | `true` | Mantén el cuerpo de la indicación oculto mientras haces que las instrucciones completas sean copiables. |
| `title` | string | Instrucción de copiar y pegar | Contexto breve mostrado junto a la acción de copiar. |
