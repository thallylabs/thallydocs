Usa `<RequestExample>` y `<ResponseExample>` para presentar ejemplos HTTP en
tarjetas separadas con encabezados. Coloca cada bloque de código directamente
dentro de su componente. Las solicitudes ofrecen un menú de lenguajes y las
respuestas muestran pestañas de estado.

## Lenguajes de solicitud y estados de respuesta

<RequestExample>
```bash cURL
curl -X POST https://api.example.com/pets \
  -H "Content-Type: application/json" \
  -d '{"name": "Buddy", "species": "dog"}'
```

```python Python
import requests

response = requests.post(
    "https://api.example.com/pets",
    json={"name": "Buddy", "species": "dog"},
)
```
</RequestExample>

<ResponseExample>
```json 201 Created
{ "id": "pet_123", "name": "Buddy", "species": "dog" }
```

```json 400 Bad Request
{ "error": "A pet name is required." }
```
</ResponseExample>

Etiqueta cada bloque de solicitud con su lenguaje, como `cURL` o `Python`. La
selección se comparte con los grupos compatibles, las tarjetas de solicitud
generadas y la ventana Try it. Si un grupo no ofrece ese lenguaje, conserva una elección anterior compatible
o muestra el primer ejemplo. La preferencia se conserva al recargar cuando el almacenamiento
del navegador está disponible.

Etiqueta cada respuesta con el código y una descripción opcional, como
`201 Created` o `400 Bad Request`. Puedes elegir una pestaña o usar las teclas
de flecha para cambiar de estado. El estado no cambia el lenguaje de solicitud.
En pantallas pequeñas, las pestañas conservan el código y ocultan la descripción.

Estas respuestas son ejemplos de tu documentación. Para ver una respuesta real
de la API, usa Try it desde una página de operación.

## Vincular campos con ejemplos

En una página de endpoint, al pasar el cursor o enfocar un parámetro o una línea
vinculada, se resaltan los nombres correspondientes en la documentación y los
ejemplos. Usa los mismos nombres en `ParamField`, `ResponseField` y las claves
de los ejemplos. Los vínculos se deducen de posiciones reconocidas, como claves
JSON, en lugar de coincidencias con cualquier texto.
