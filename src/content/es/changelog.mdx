## Actualizaciones y versiones del producto

<Update label="Referencia de API y tarjetas de código" date="2026-10-21">
  La navegación de endpoints ahora incluye etiquetas de método HTTP. Las páginas de API tienen tarjetas separadas de solicitud y respuesta, selección compartida de lenguaje, resaltado de parámetros vinculados y una ventana Try it adaptable con validación de campos. Los controles de código y la navegación móvil también se adaptan a pantallas pequeñas.

  Consulta [Genera una referencia de API](/es/guides/api-reference-setup), [Configura el playground de API](/es/guides/api-playground) y [Bloques de código](/es/components/code-blocks).
</Update>

<Update label="Actualizaciones de migración" date="2026-09-30">
  La CLI de migración ahora tiene adaptadores dedicados para repositorios de Mintlify, Fern y Docusaurus. Esta versión mejora el manejo de navegación, enlaces, assets, referencias de API, páginas traducidas y componentes locales en esas fuentes. También traslada la configuración de pie de página de Docusaurus compatible al sitio generado.

  El importador escribe `migration-report.json` con advertencias y resultados de validación. Revisa ese informe y compara el sitio local con su origen antes de publicar. Consulta la [guía de migración](/es/guides/migrating) y la [referencia de la CLI](/es/guides/cli-reference#migra-documentación-existente).
</Update>
