Utilisez `<Tree>`, `<Folder>`, et `<File>` pour représenter les structures de répertoires dans votre documentation. Les dossiers sont interactifs — cliquez pour les développer ou les réduire.

## Exemple

<Tree>
  <Folder name="src" defaultOpen>
    <Folder name="app">
      <File name="page.tsx" />
      <File name="layout.tsx" />
    </Folder>
    <Folder name="components">
      <File name="button.tsx" />
      <File name="card.tsx" />
    </Folder>
    <File name="globals.css" />
  </Folder>
  <File name="package.json" />
  <File name="tsconfig.json" />
  <File name="next.config.ts" />
</Tree>

```mdx
<Tree>
  <Folder name="src" defaultOpen>

  </Folder>
  <File name="package.json" />
```

## Props

### `<Tree>`
Élément conteneur — fournit le conteneur stylisé. Aucune prop supplémentaire.

### `<Folder>`

| Prop | Type | Par défaut | Description |
|---|---|---|---|
| `name` | `string` | — | Nom du dossier affiché à côté de l'icône |
| `defaultOpen` | `boolean` | `false` | Si le dossier commence développé |

### `<File>`

| Prop | Type | Description |
|---|---|---|
| `name` | `string` | Nom du fichier affiché à côté de l'icône |
