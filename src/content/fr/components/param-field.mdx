`<ParamField>` affiche une entrée de paramètre structurée pour la documentation des requêtes API. Utilisez les props `body`, `query`, `path` ou `header` pour spécifier l'emplacement du paramètre.

## Exemple

<ParamField body name="name" type="string" required>
  Le nom de l'animal. Doit être entre 1 et 100 caractères.
</ParamField>

<ParamField query name="limit" type="integer" default="20">
  Nombre de résultats à retourner. Le maximum est 100.
</ParamField>

<ParamField path name="petId" type="string" required>
  L'identifiant unique de l'animal.
</ParamField>

<ParamField header name="Authorization" type="string" required>
  Jeton Bearer pour l'authentification : `Bearer sk-...`
</ParamField>

```mdx
<ParamField body name="name" type="string" required>
  The name of the pet.
</ParamField>

<ParamField query name="limit" type="integer" default="20">
  Maximum results to return.
</ParamField>

<ParamField path name="petId" type="string" required>
  The unique identifier.
</ParamField>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `name` | `string` | Nom du paramètre |
| `type` | `string` | Type de données (par ex. `string`, `integer`, `boolean`) |
| `body` | `boolean` | Marque comme paramètre de corps de requête |
| `query` | `boolean` | Marque comme paramètre de chaîne de requête |
| `path` | `boolean` | Marque comme paramètre de chemin |
| `header` | `boolean` | Marque comme en-tête de requête |
| `required` | `boolean` | Affiche un badge « required » |
| `default` | `string` | Valeur par défaut affichée en ligne |
