Utilisez `<RequestExample>` et `<ResponseExample>` pour encadrer les paires de requêtes/réponses HTTP dans la documentation API écrite en MDX. Ils ajoutent une barre d'en-tête étiquetée — bleue pour les requêtes, verte pour les réponses — correspondant au style utilisé par les pages de référence API générées automatiquement.

## Exemple

<RequestExample>
```bash cURL
curl -X POST https://api.example.com/pets \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{"name": "Buddy", "species": "dog"}'
```
</RequestExample>

<ResponseExample>
```json 201 Created
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "Buddy",
  "species": "dog",
  "status": "available",
  "created_at": "2025-01-15T10:30:00Z"
}
```
</ResponseExample>

```mdx
<RequestExample>
\`\`\`bash cURL
curl -X POST https://api.example.com/pets \
  -H "Authorization: Bearer sk-..." \
  -d '{"name": "Buddy", "species": "dog"}'
\`\`\`
</RequestExample>

<ResponseExample>
\`\`\`json 201 Created
{ "id": "a1b2c3d4", "name": "Buddy", "status": "available" }
\`\`\`
</ResponseExample>
```

## Avec CodeGroup

Enveloppez un `<CodeGroup>` à l'intérieur de `<RequestExample>` pour afficher la même requête dans plusieurs langages :

```mdx
<RequestExample>
  <CodeGroup>
  \`\`\`typescript TypeScript
  await client.pets.create({ name: 'Buddy', species: 'dog' })
  \`\`\`

  \`\`\`python Python
  client.pets.create(name="Buddy", species="dog")
  \`\`\`
  </CodeGroup>
</RequestExample>
```
