Utilisez `<Badge>` pour mettre en évidence le statut, les versions ou les catégories en ligne dans le texte ou les en-têtes.

## Modèles courants

Placez les badges à côté d'un en-tête de page pour afficher le statut d'une fonctionnalité :

```mdx
## Webhooks <Badge variant="warning">Beta</Badge>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `"default" \| "success" \| "warning" \| "danger" \| "info"` | `"default"` | Schéma de couleurs |
