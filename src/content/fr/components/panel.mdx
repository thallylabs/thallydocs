`<Panel>` est une section visuellement contenue sans la couleur affirmée des callouts. Utilisez-le pour regrouper du contenu connexe ou mettre en évidence un bloc sans impliquer une urgence.

## Exemple

<Panel title="Configuration">
  Définissez votre clé API dans le fichier `.env` avant d'exécuter l'application.

  ```bash
  API_KEY=sk-your-key-here
  ```
</Panel>

<Panel>
  Les panneaux sans titre sont également pris en charge.
</Panel>

```mdx
<Panel title="Configuration">
  Set your API key in the `.env` file.
</Panel>

<Panel>
  Content without a title.
</Panel>
```

## Props

| Prop | Type | Par défaut | Description |
|---|---|---|---|
| `title` | `string` | — | En-tête optionnel affiché au-dessus du contenu |
