`<Color>` affiche un aperçu de couleur avec un nom optionnel et une étiquette hexadécimale. Utilisez-le sur les pages de directives de marque ou la documentation du système de conception.

## Exemple

<Color hex="#10B981" name="Emerald" />
<Color hex="#8B5CF6" name="Violet" />
<Color hex="#F59E0B" name="Amber" />
<Color hex="#EF4444" name="Rose" />

```mdx
<Color hex="#10B981" name="Emerald" />
<Color hex="#8B5CF6" name="Violet" />
<Color hex="#F59E0B" name="Amber" />
<Color hex="#EF4444" name="Rose" />
```

## Dans une grille

Utilisez `<Columns>` pour disposer plusieurs nuances côte à côte :

<Columns cols={4}>
  <Color hex="#10B981" name="Emerald" />
  <Color hex="#8B5CF6" name="Violet" />
  <Color hex="#F59E0B" name="Amber" />
  <Color hex="#EF4444" name="Rose" />
</Columns>

```mdx
<Columns cols={4}>
  <Color hex="#10B981" name="Emerald" />
  <Color hex="#8B5CF6" name="Violet" />
  <Color hex="#F59E0B" name="Amber" />
  <Color hex="#EF4444" name="Rose" />
</Columns>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `hex` | `string` | Valeur de couleur hexadécimale incluant `#` (par ex. `#10B981`) |
| `name` | `string` | Nom d'affichage optionnel affiché au-dessus du code hexadécimal |
