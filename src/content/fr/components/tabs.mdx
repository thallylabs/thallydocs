`<Tabs>` et `<Tab>` créent un panneau de contenu avec onglets. Utilisez-les pour les instructions spécifiques à une plateforme, les variantes linguistiques, ou tout contenu où les utilisateurs doivent choisir un chemin.

## Exemple

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @company/sdk
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @company/sdk
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @company/sdk
    ```
  </Tab>
</Tabs>

````mdx
<Tabs>
  <Tab title="npm">
    ```bash
    npm install @company/sdk
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @company/sdk
    ```
  </Tab>
</Tabs>
````

## Contenu riche des onglets

Les onglets peuvent contenir n'importe quel contenu MDX, y compris des légendes, des groupes de code et des images :

````mdx
<Tabs>
  <Tab title="macOS">
    <Steps>
      <Step title="Install Homebrew">
        ```bash
        /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Windows">
    Download the installer from the releases page.
  </Tab>
</Tabs>
````

## Props

### `<Tab>`

| Prop | Type | Description |
|---|---|---|
| `title` | `string` | Étiquette affichée sur le bouton d'onglet |
