Thally fournit deux serveurs Model Context Protocol. Le **serveur local** aide
un agent de codage IA à travailler sur un référentiel. Le **serveur distant** aide un agent
à consulter la documentation déjà publiée par un site.

## MCP local et distant

| | Serveur d'édition local | Serveur de site déployé |
| --- | --- | --- |
| Point de terminaison | `npx -y @thallylabs/mcp` ou `npx --yes @thallylabs/cli@latest mcp` | `https://docs.example.com/api/mcp` |
| Transport | stdio | HTTP diffusable |
| Accès | Votre machine et permissions du système de fichiers | Public par défaut ; lecture seule et limité en débit |
| Outils | 15 outils de projet et de site | 4 outils de site |
| À utiliser pour | Créer, éditer, migrer, traduire et valider des docs | Rechercher, lire, lister les pages et vérifier la disponibilité |

## Ce que le serveur local expose

Le paquet local enregistre 15 outils à partir d'un registre partagé :

- **Créer et organiser :** `create_project`, `add_page`, `update_page`,
  `add_tab`, `list_pages`
- **Lire et rechercher :** `read_page`, `search_docs`, `get_context`
- **Migrer et traduire :** `migrate_docs`, `import_docs`, `translate_docs`
- **Valider et inspecter :** `lint_project`, `semantic_search`,
  `agent_readiness`
- **Automatiser les changements de produit :** `sync_from_repo`

La plupart des outils agissent sur un `projectDir` local. `semantic_search` et
`agent_readiness` interrogent un `siteUrl` déployé. Le serveur retourne des
erreurs structurées lorsque les chemins ou valeurs requises sont manquants, afin que votre agent puisse corriger l'
appel au lieu d'inférer un résultat.

## Connecter un site déployé

Remplacez l'URL d'exemple par l'origine du site de documentation.

<Tabs>

<Tab title="Codex">

```bash
codex mcp add product-docs --url https://docs.example.com/api/mcp
```

</Tab>

<Tab title="Claude Code">

```bash
claude mcp add --transport http product-docs https://docs.example.com/api/mcp
```

</Tab>

<Tab title="Cursor">

```json
{
  "mcpServers": {
    "product-docs": {
      "type": "http",
      "url": "https://docs.example.com/api/mcp"
    }
  }
}
```

</Tab>

</Tabs>

Le point de terminaison déployé expose `search_docs`, `read_page`, `list_pages`, et
`agent_readiness`. Il ne peut pas éditer le site. Les propriétaires de site peuvent le désactiver depuis le
tableau de bord d'administration, et les appels d'outils publics par défaut à une limite par adresse IP de 60 par
minute.

## Comportement d'écriture sécurisé

Le point de terminaison distant public est toujours en lecture seule. Les outils MCP locaux héritent des
permissions du processus qui les a démarrés, alors examinez toute demande qui écrit
des fichiers. `migrate_docs` nécessite une cible nouvelle ou vide ; `import_docs` modifie un
projet existant et ne doit être utilisé que lorsqu'une fusion sur place est intentionnelle.

Continuez vers la [référence d'outil MCP local](/guides/mcp-server) ou le
[guide MCP distant](/guides/remote-mcp) pour tous les outils et options.
