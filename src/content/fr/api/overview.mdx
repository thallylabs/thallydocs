## Premiers pas avec la documentation API

Ce site n'inclut pas d'exemple de spécification API ou de pages de points de terminaison générés. Pour publier une référence API complète, vous devrez ajouter votre propre spécification OpenAPI 3.x et la connecter via la configuration du projet.

## Comment configurer votre référence API

Pour publier une référence API, ajoutez votre propre spécification OpenAPI 3.x et connectez-la dans `docs.json`. Suivez [Configurer une référence API](/guides/api-reference-setup) pour connaître les options de configuration supportées et les étapes de validation. Ce guide couvre tout ce que vous devez savoir sur la configuration des points de terminaison, la personnalisation des pages d'opération et la rendre votre documentation API découvrable pour vos utilisateurs.
